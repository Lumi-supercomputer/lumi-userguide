# Contribution and Feedback


## Contribution to LUMI docs

We welcome contributions to our documentation!

To contribute to LUMI docs, we recommend to either open an issue in [github](https://github.com/Lumi-supercomputer/lumi-userguide/) or to directly make a pull request to suggest a change (please see the short [contribution guide](https://github.com/Lumi-supercomputer/lumi-userguide/blob/production/CONTRIBUTING.MD) for this).

Alternatively, you can also suggest a change to LUMI docs using the feedback form (see below). 

The LUMI staff considers the suggestions with taking account the overall picture with LUMI, and although we are very grateful for all improvement ideas, not necessarily all change suggestions are implemented. 


## General feedback 

If you want to give us general feedback, please fill the **[feedback form](https://lumi-supercomputer.eu/user-support/need-help/feedback/)**!

Please notice that the messages sent via the feedback support form are not considered urgent. With an actual problem with LUMI, please report the issue with using some of the other support forms.
