# Infrastructure for AI agents

[agent environment]: ./agent-env.md
[firecrest mcp]: ./firecrest-mcp.md
[knowledge mcp]: ./knowledge-mcp.md

The LUMI AI Factory develops software infrastructure that supports the use of AI agents for
LUMI-related tasks. The current offering comprises:

* [Agent environment][agent environment]: a containerized environment for using the OpenCode
  coding agent on LUMI.
* [FirecREST MCP Server][firecrest mcp]: an MCP server that you run locally to give agents
  access to LUMI through the FirecREST HPC API, with guardrails in place.
* [Knowledge MCP Server][knowledge mcp]: a public MCP server that provides agents access to
  relevant user documentation and LUMI service status.
